## P0-1: db.py + data_loader.py

**功能**：DB 简洁够用，SQLite 正确。data_loader 尽力提取 fin_db 指标，API 格式多变是现实约束。
**交互**：纯后端，无交互面。
**股民喜好度**：⭐⭐⭐（底座无感但必须稳）
**改进方向**：
1. 加 LRU 查询缓存，避免重复消耗额度
2. 积累 fin_db 响应样本后做鲁棒解析器
3. 自选支持分组（科技/消费/实验仓）
4. 数据时间戳标注新鲜度


## P0-2: Watchlist 自选股池

**功能**：增删查正常，模拟价格匹配可用，DB 持久化。
**交互**：侧边栏添加 + 表格展示 + 底部快捷删除双入口。但删除按钮布局在6列限制下可能溢出。
**股民喜好度**：⭐⭐⭐⭐（核心刚需，简单直接）
**改进方向**：
1. 添加后自动匹配实时价格（目前只有模拟数据匹配8只）
2. 支持拖拽排序、分组
3. 空状态引导不够强，新用户不知道去哪加
4. 表头"点击名称进个股页"没有明确提示
5. 删除需要滚动找按钮，应该在表格行内直接删


## P0-3: Stock 个股深度页

**功能**：财报指标卡片 + 事件时间线 + AI入口 + 自选联动。fin_db 解析有时空。
**交互**：URL参数驱动，从Watchlist点击直达。空白页支持手动输代码。指标6列卡片一目了然。
**股民喜好度**：⭐⭐⭐⭐⭐（核心页面，秒懂一只票）
**改进方向**：
1. 财报数据不稳定（fin_db 格式多变），需要更鲁棒的解析
2. 缺产业链/竞品对比（P2 会补）
3. 缺少历史趋势图（营收/利润曲线）
4. 事件时间线应该可筛选类型（财报/公告/调研）
5. 加入券商评级/目标价数据


## P1-1: Dashboard 异动监控

**功能**：Dashboard 新增 MARKET MOVERS 区，8只异动票 2x4 网格，点击进个股页。
**交互**：卡片式，涨跌幅红绿色区分，clickable 跳转 Stock 页。
**股民喜好度**：⭐⭐⭐⭐（散户开盘第一眼看的就是涨跌幅榜）
**改进方向**：
1. 目前是模拟数据，需接入真实行情（AKShare）
2. 缺少"成交量突增""换手率异常"等异动维度
3. 应该加一个切换：涨幅榜 / 跌幅榜 / 振幅榜

## P1-2: Search 公告语义搜索

**功能**：搜索页上方加 8 个快捷标签（减持/增持/业绩预告/重大合同/分红/回购/股权激励/重组），点击自动搜。
**交互**：一键填充关键词，减少打字。
**股民喜好度**：⭐⭐⭐⭐（散户最关心的公告类型一键直达）
**改进方向**：
1. 标签点击后应该直接触发搜索，目前只填充需要再点搜索
2. 应该支持多标签组合
3. 加"我的关注"标签——搜自选股的公告


## P2-1: AI Chat 简报+摘要

**功能**：新增 [BRIEF] [SUMMARY] [COMPARE] 三个快捷按钮。摘要模式搜索 announcement+web 聚合。
**交互**：按钮区在输入框上方，填写内容后一键触发，自动加前缀词。
**股民喜好度**：⭐⭐⭐⭐（减少打字，散户懒人福音）
**改进方向**：
1. 摘要应该真正 AI 生成而不是拼接 snippet
2. 简报应该基于 fin_db 数据自动生成结构化输出
3. 按钮应该在无输入时也能用（引导用户先输入）

## P2-2: Compare 同业横比

**功能**：两侧边栏输代码 → 7指标并排对比 → 判定胜负。指标优劣自动标绿。
**交互**：三列网格布局，指标名居中，A/B 各占一列，胜出方绿色高亮。
**股民喜好度**：⭐⭐⭐⭐⭐（散户选股核心需求——比一比）
**改进方向**：
1. 应该支持从 Watchlist 直接选股对比
2. 加历史趋势对比图（营收/利润走势）
3. 判定太简单（只有计数），应该有加权打分
4. PE 越低越好的逻辑应该考虑行业差异

## P2-3: Calendar 财报日历+调研

**功能**：双列布局——业绩预告 / 机构调研。日期+标题+摘要卡片。
**交互**：左右并排，时间轴式卡片，调研用 VISIT 标签。
**股民喜好度**：⭐⭐⭐（有用但非高频，财报季集中使用）
**改进方向**：
1. 应该按日期排序成日历视图
2. 筛选只显示自选股的预告/调研
3. 加"未来2周""未来1月"时间切换

## P3-1: 研报AI摘要

**功能**：SUMMARY 按钮触发多源搜索（announcement+web）聚合摘要。
**交互**：一键聚合8条来源的 snippet。
**股民喜好度**：⭐⭐⭐（方向对但摘要质量依赖 snippet 质量）
**改进方向**：
1. 接入真正的 LLM 做摘要（目前只是拼接）
2. 应该结构化输出：核心观点/评级/目标价/风险
